# תורת הצבע · גלגל ניוטון למעצבים

**כתובת:** https://anat1969.github.io/PixelColorsCircle-GH/

אפליקציית ווב בעברית (RTL) שהופכת את תורת הצבע לכלי עבודה: בונים פלטה על גלגל הצבעים של ניוטון, הכלי מחשב הרמוניה, טמפרטורה וניגודיות לפי WCAG, מסביר כל צבע לאורך הספקטרום, ומראה מה צבע עושה בטבע, במוזיקה ובפיזיקה.

נבנה עבור אד' ענת שטיבלמן (A&I).

## על מה הכלי נשען

- **ניוטון, Opticks (1704):** מעגל שבעת הצבעים.
- **יוהנס איטן, אמנות הצבע (1961):** שמות ההרמוניות (משלימה, משולש, משלימה מפוצלת, ריבוע, מלבן, אנלוגית).
- **WCAG 2.2, סעיפים 1.4.3 ו־1.4.6:** נוסחת הבהירות היחסית וספי הניגודיות 3:1, 4.5:1 ו־7:1.
- **ISO 3664:** רקע אפור ניטרלי לשיפוט צבע. הממשק כולו בשחור, לבן ו־50 גוונים של אפור, כך שהצבע היחיד על המסך הוא הצבע הנחקר.

כל חישוב מוצג כחישוב, וכל פרשנות מסומנת כפרשנות. מגבלות הכלי כתובות בדוח עצמו.

## כפתור הלוגו A&I

בסרגל העליון יש רק את שם האפליקציה (קישור לדף הבית), את ניווט התוכן ואת כפתור הלוגו. כל פעולות הפיתוח והעריכה נמצאות בתוכו: העתקת קישור (כולל מצב הגלגל הנוכחי), שיחת הפיתוח, התקנת האפליקציה, מצב עריכה (עריכת טקסטים והעלאת תמונות) ושחזור הטקסטים המקוריים. התקן: [ai-menu-standard](https://github.com/Anat1969/AppOfApp-GH/blob/main/docs/ai-menu-standard.md).

## הרצה

```bash
npm install
npm run dev          # http://localhost:8080
npm test             # בדיקות יחידה (Vitest)
npm run test:e2e     # בדיקות קצה לקצה (Playwright), דסקטופ ונייד
npm run build        # גרסת ייצור ל-dist/
```
